How to Use iTópos

Upload your own list of Pleiades places from Excel, CSV, or text. Your file is processed entirely in your browser and is not stored by this site.

Prepare your file

Each place needs a Pleiades ID. The simplest file is one column of IDs; canonical Pleiades place URIs are accepted too. A header row is optional and case-insensitive.

Accepted ID headers:

idpidplace_idpleiades_idpleiadesuri

Add groups (optional)

Add a group column to categorize places. Use one group name per row. Repeat an ID on additional rows when a place belongs to more than one group.

Upload your file

Drag and drop the file into Upload, or choose a file. Excel (.xlsx, .xls) and CSV/text (.csv, .txt) are supported. Extra columns are ignored; hidden or filtered Excel rows are skipped; all worksheets are processed.

Build a map from Pleiades by searching ID, place name, feature category, and/or time period. Each search provides a way into the Pleiades corpus. Filter Search Options can then cross-reference selected criteria to narrow the mapped Places. Unlocated places cannot be mapped and are excluded.

Find places

Select one or more ID or place-name suggestions. ID suggestions match the beginning of the ID. Place names are not unique, so use the Pleiades ID and representative point when you need to distinguish records.

Feature categories

Select one or more feature categories. With two or more categories, Match Any (OR) finds places with any selected type and Match All (AND) requires every selected type. Selected types can also narrow results already found by ID or name.

Time Period

Find places with one or more locations and names with attested time-periods. Search the list by name. Multiple selected time periods are treated as alternatives (OR). Use Filter Search Options to cross-reference the result with other Browse criteria.

Choose and map search results

Results show the Pleiades ID, representative point, and feature categories for each selected place. Use All, None, or individual checkboxes to customize the list. Then, choose Map places.

Home button

Use the Home button located on the right side of the map to reset the zoom level.

Cluster / individual Places

Toggle clustering to inspect individual Places without zooming further. Clustering is recommended for large datasets and overview maps. Disabling clustering can render slowly or lag with large datasets.

Explore

Once places are mapped, in Explore, click a group or feature category to focus matching places. Esc clears the current focus.

Clustered places

A numbered map pin represents nearby places at the current zoom. Click it to zoom in. During Temporal Exploration, a fraction such as 4/12 shows places matching the active time period(s) out of all places in the cluster.

Co-located places

Multiple places share the same representative point. Click the marker to inspect them.

Pleiades time-periods can overlap and can be geographically specific; they are not a singular or contiguous historical timeline. Temporal Exploration uses Pleiades time-period attestations to show how the mapped corpus changes across overlapping periods.

Choose time periods

The score starts with a small selection of periods represented in the mapped corpus. Use the clock to search the available periods and choose which lines are displayed. Each line shows that period's date range, so overlaps and nested periods remain visible.

Choose attestation confidence

Use the gear to include or exclude Pleiades attestation-confidence levels. These settings change which temporal evidence participates in the score, map, and statistics.

Select and compare time-periods

Click or tap a line to view one period. On a keyboard, Ctrl/Cmd-click deliberately combines periods. The map and temporal statistics update from the active selection. Disable temporal filtering to keep the score visible without filtering the map.

Read the map and popups

Individual Places with matching temporal evidence remain prominent while other mapped Places recede. Place markers can show counts of attested Locations and Names. Cluster pins show nearby Place totals; during temporal filtering they show active/total fractions. Popups always show available temporal evidence and highlight the active period rows.

A Place without evidence for the active period remains part of the mapped corpus. Temporal Exploration does not assert that the Place did not exist. Pleiades Locations or Names without a time-period attestation are reported as an unspecified date range.

▶

Play through the score

Playback walks through the selected displayed periods in start-date order. Only the period currently being played is highlighted. Pause keeps the current period; Stop restores all displayed periods.

For smaller datasets, disabling clustering can make the changing individual Places easier to see. For large datasets, keep clustering enabled to avoid slow rendering.
